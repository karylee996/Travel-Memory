# Travel-Memory

A compact image-generation Skill for creating refined **3:4 travel-memory posters** from a single photograph.

## Signature layout

- 3:4 vertical
- exact 50/50 horizontal split
- faithful photo on top
- warm ivory illustrated journal on bottom
- 9 source-derived illustrations
- invisible 3×3 alignment
- small centered elements
- generous negative space
- no grid lines, no boxes, no ticket/sticker clutter

See [SKILL.md](./SKILL.md) for the full generation workflow and constraints.
