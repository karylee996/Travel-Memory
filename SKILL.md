# Travel-Memory

## Purpose

Turn one uploaded travel/lifestyle photograph into a refined **3:4 vertical travel-memory poster** that combines:
1. a faithful photographic upper half, and
2. a spacious hand-drawn illustrated memory journal in the lower half.

The style should feel like a premium travel magazine mixed with a handmade visual diary: warm, restrained, nostalgic, elegant, and highly editorial.

---

## Core Layout

- Final aspect ratio: **3:4 vertical**
- Use a **strict horizontal 50/50 split**
- Upper 50%: original photograph
- Lower 50%: illustrated memory journal
- Use one source photo only
- Never create multi-photo collage output
- Keep the split visually clean and straight
- No blur, feathering, gradient transition, tearing, overlap, or objects crossing the midpoint

---

## Upper Half — Original Photo

Use the uploaded image as the primary reference and preserve it faithfully.

### Must preserve
- main subject identity
- people count
- architecture
- object count
- pose and direction
- spatial relationships
- camera angle
- perspective
- environment
- recognizable structural features
- original atmosphere
- natural materials and textures

### Allowed edits
Only subtle photographic finishing:
- gentle warm or cinematic color grading
- mild tonal balancing
- slight contrast refinement
- very light film grain

### Do not
- repaint the photo
- stylize it into an illustration
- add or remove people
- alter architecture
- move objects
- mirror the scene
- distort perspective
- invent new visual content

---

## Lower Half — Illustrated Memory Journal

Use a warm ivory / soft off-white textured paper background.

Extract **exactly 9 recognizable visual memories** from objects, scenery, architecture, details, atmosphere, or activities that are actually visible in the source photo.

Examples:
- landmark
- building façade
- bridge
- river
- chair
- lantern
- tree
- cloud
- signboard
- stone wall
- boat
- lamp
- window
- table
- tools
- flowers
- mountain
- reflection
- path
- people silhouette

Do not invent unrelated objects.

---

## Invisible 3×3 Grid

Arrange the 9 memories using a **3×3 invisible editorial grid**.

Important:
- the grid is only a layout system
- **never draw visible boxes**
- **never draw grid lines**
- no separate borders around each illustration
- each illustration should be relatively small
- center each illustration inside its invisible cell
- leave generous space between items
- keep all 9 elements visually balanced
- maintain noticeably large margins on the left, right, top, and bottom of the lower section

The result should feel spacious and expensive rather than full or crowded.

### Visual density target
- illustration content occupies roughly 45–60% of the lower-half area
- negative space is a major design element
- avoid oversized illustrations
- avoid elements touching each other
- avoid filling every empty area with decoration

---

## Illustration Style

Each memory vignette should use:

- delicate hand-drawn pencil structure
- fine ink outlines
- loose colored-pencil shading
- soft transparent watercolor washes
- mild pigment variation
- imperfect handmade strokes
- subtle paper bleed
- slightly unfinished edges
- restrained colors sampled or inspired by the original photo

The result must remain clearly illustrative, not photorealistic.

### Preferred aesthetic
- refined
- editorial
- warm
- natural
- nostalgic
- handcrafted
- quiet
- elegant
- lightly playful

### Avoid
- 3D rendering
- vector icon look
- cartoon exaggeration
- glossy digital painting
- hyperreal miniatures
- sticker aesthetic
- heavy graphic design
- thick outlines
- saturated neon colors

---

## Typography

Add a small handwritten title near the top of the lower section.

The title should adapt naturally to the source photo, for example:
- 京都回忆
- 姬路城回忆
- 夏日小记
- 工作室的记忆
- Camping Memories
- Nara Memories
- Travel Memories

Optionally add a very small restrained English subtitle beneath it.

Each of the 9 illustrations should have a short handwritten label directly below it.

Labels should:
- be concise
- identify the illustrated element
- use the language most natural for the scene
- remain small and understated

Examples:
- 石灯笼
- 河畔餐厅
- 散步小路
- 和船游览
- 彩色椅子
- 工作台灯
- 城墙与绿意
- 远处的山与云

At the very bottom, add one tiny handwritten emotional closing line, for example:
- 值得铭记的完美一天 ♡
- 值得铭记的美好旅程 ♡
- 把平凡的日子，过成喜欢的样子 ♡
- A Perfect Day to Remember ♡

Typography should always remain subtle and secondary to the artwork.

---

## Decorative Doodles

A very small number of hand-drawn doodles may be used:
- tiny leaf
- heart
- sparkle
- small sun
- moon
- wave
- cloud
- simple arrow

Rules:
- use sparingly
- keep them tiny
- never fill empty space just because it is empty
- preserve the clean editorial feel

---

## Absolute Constraints

- one original photo only
- one illustrated memory section only
- 3:4 vertical output
- strict 50/50 horizontal split
- top must remain realistic photography
- bottom must use exactly 9 source-derived illustrated memories
- 3×3 layout logic only; no visible grid
- illustrations small and centered
- generous negative space
- no individual frames
- no borders around objects
- no ticket stubs
- no scrapbook stickers
- no travel ephemera
- no taped-paper collage
- no 3D elements
- no irrelevant invented objects
- no crowded composition
- no excessive decorative elements
- no unrelated typography
- no visual crossover between the photo and illustration halves

---

## Generation Workflow

When a user provides a photo:

1. Inspect the uploaded photo carefully.
2. Identify the scene, mood, and likely location/theme only when visually justified.
3. List the 9 strongest visible memory elements.
4. Preserve the original image faithfully in the upper half.
5. Reinterpret the 9 selected memories into delicate watercolor-pencil miniatures.
6. Place them on an invisible 3×3 grid with large margins and generous spacing.
7. Add one subtle handwritten title and short labels.
8. Add one tiny closing sentence.
9. Keep decorative doodles minimal.
10. Check that the final artwork looks more like an editorial travel journal than a conventional scrapbook.

## Prompt Template

将上传照片制作成一张 **3:4 竖版高级旅行记忆海报，上下严格 1:1**。

上半部分忠实使用原始照片，准确保留主体、人物数量、建筑、物体、空间关系、构图、视角、透视、自然光线、材质和原有氛围，仅进行轻微、自然、略带电影感的调色和极薄颗粒处理。不得重绘照片，不得增删人物或物体，不得改变建筑、位置、比例、方向或透视。

下半部分使用温暖象牙白或柔和米白色纹理纸。从原始照片中提取 **9 个真实可见、最有代表性的视觉元素**，重新绘制为精致的手绘小插画。插画采用细腻铅笔与墨线轮廓、松散彩色铅笔和淡彩水彩上色、轻微纸张渗色、不完美手工笔触与柔和低饱和色彩。

9 个插画按照 **3×3 隐形九宫格**整齐排列。九宫格仅作为排版逻辑，**不要绘制任何格子、分割线或单独边框**。每个插画尺寸偏小，独立居中，彼此之间保持明显间距。下半部分四周以及元素之间保留大量留白，让画面疏朗、安静、克制、高级。不要为了填满画面而放大插画或增加装饰。

在下半部分顶部加入一个与照片地点或主题相关的简洁手写标题，可附很小的英文副标题。每个插画下方加入一个简短手写名称。可极少量加入叶子、爱心、星光、太阳、月亮、云朵或波浪等微型手绘符号。最底部加入一句很短的旅行或记忆感言。

整体效果应像 **高级旅行杂志 × 手工视觉日记**：温暖、怀旧、自然、精致、克制、留白充足。

禁止：3D 渲染、照片级插画、复杂拼贴、票根、贴纸、胶带、撕纸、独立边框、明显九宫格线、无关装饰、虚构物体、过度饱和色彩、拥挤排版、多图拼接。
